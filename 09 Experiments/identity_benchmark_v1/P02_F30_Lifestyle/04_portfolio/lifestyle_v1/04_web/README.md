# Web exports

Ten JPEG and ten WebP derivatives from staging, linked by `web_manifest.csv`.
Long edge is at most 1600 px; smaller images are not enlarged. Aspect ratio is preserved.
JPEG quality 95, no chroma subsampling; WebP quality 95, method 6. RGB exports omit source
metadata. No retouch or AI upscale. Original PNGs remain byte-identical.
